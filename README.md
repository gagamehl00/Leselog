# Leselog

Minimalistische Lese-App: Bücher suchen, bewerten, automatisch kategorisieren, Merkliste und Lesestatistik.

- Läuft komplett im Browser, Daten bleiben lokal auf dem Gerät (localStorage)
- Buchsuche über Google Books und Open Library
- Backup als JSON exportieren und importieren

Live: https://gagamehl00.github.io/Leselog/
